## Overview

Rob Papen Go2 delivers professional synthesis in an accessible interface, featuring dual oscillators, a versatile filter, and an extensive modulation matrix at an entry-level price.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Rob Papen Go2** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Dual Oscillators** | Waveform blending with FM, ring mod, and hard sync modes |
| **X-LFO** | Rob Papen's signature cross-modulation LFO for complex motion |
| **Arp/Sequencer** | Built-in arpeggiator and step sequencer with MIDI export |
| **Effects** | Chorus, phaser, delay, and reverb post-processing chain |
